# Crisp 功能测试版

这份安装包包含三个尚未合并上游的功能：单屏连接滑钮、多屏批量连接和断开、保持工具展开。

源码版本：e1492491621982ac6d3fb0db95c1ad31b72f34e6。应用基于 Crisp 1.7.0，测试构建号 17001。安装包包含 arm64 和 x86_64 两种架构。显示器断开功能只支持 Apple Silicon。

## 安装

1. 从菜单退出正在运行的 Crisp。
2. 将现有的 `/Applications/Crisp.app` 备份到另一个文件夹。
3. 将本磁盘映像中的 `Crisp.app` 拖到 `Applications`，选择替换现有版本。
4. 打开应用。测试版与原版使用同一应用标识，会读取现有设置；不要同时运行两个版本。
5. 如果 macOS 阻止打开，在系统设置的“隐私与安全性”中，对这个应用选择“仍要打开”。不要关闭整个系统的安全检查。

这是 ad-hoc 签名的个人测试构建，未经过 Apple 公证。自动更新的默认选项已关闭；已有用户设置可能覆盖默认值，测试期间不要通过应用更新到官方版。

更换签名可能使原有辅助功能授权失效。仅在测试亮度键时，按应用提示重新授权；显示器连接滑钮不需要亮度键权限。

## 测试

1. 在每台显示器展开区的“显示器连接”行，用右侧滑钮断开；在“已断开”区用滑钮重新连接。
2. 展开“工具”，确认批量连接开关、全部重连、全部断开在“自动断开内建显示器”和“虚拟显示器”之间。
3. 多屏状态下测试批量操作。全部断开会保留一块可用实体屏，优先保留活动内建显示器，其次为主显示器。
4. 在设置开启“保持工具展开”，关闭菜单后重新打开，再退出并重新启动应用；确认工具仍展开。
5. 关闭这个设置，确认工具可以正常折叠，并在关闭菜单后恢复折叠。

真实显示器切换、睡眠恢复等硬件结果尚未被本次构建验证。请记录异常前的显示器组合、执行的操作及现象。

## 恢复原版

退出测试版，将备份的原版 `Crisp.app` 放回 `Applications`。也可以重新安装作者发布的正式版。应用备份不会自动恢复测试期间更改的设置。

## 源码

`SourceCode.zip` 是同一源码版本的完整仓库快照。预编译应用可以直接安装，无需 Xcode。自行编译时需要配套的完整 Xcode 和 macOS 26 或更新 SDK。
